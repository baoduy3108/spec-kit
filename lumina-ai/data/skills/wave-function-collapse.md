# Wave Function Collapse (WFC)

Wave Function Collapse is a procedural generation algorithm that produces output looking **coherent and hand-authored** from a tiny set of rules or a single example image. It's borrowed-name-from-physics but really a **constraint-satisfaction** solver over a grid — popular for tile maps, textures, and level layouts.

## The Idea

Every cell in the grid starts in a **superposition** — it *could* be any tile. Tiles have **adjacency constraints** (which tiles may sit next to which, per direction). The algorithm repeatedly picks a cell, **collapses** it to one definite tile, and **propagates** the consequences (neighbors lose now-impossible options), until every cell is decided. The result respects all local rules everywhere, so it reads as intentional — roads connect, walls close, biomes blend — despite being random.

## The Loop

1. **Initialize** — every cell's set of possible tiles = all tiles.
2. **Observe (collapse)** — find the cell with the **lowest entropy** (fewest remaining options — the most constrained, most likely to fail if left). Collapse it to one tile, chosen randomly weighted by tile frequency.
3. **Propagate** — remove options from neighbors that are now incompatible with the collapsed tile; cascade those removals outward (a queue/worklist) until no more change. This is arc-consistency (AC-style) propagation.
4. **Repeat** until all cells collapsed — or a cell's option set becomes **empty** (a contradiction).

Choosing the lowest-entropy cell is key: it collapses the riskiest cells first, keeping options open elsewhere.

## Where Rules Come From

- **Overlapping model** — feed a small **example image**; WFC extracts every N×N pattern and their adjacencies automatically. You give it a sample of the style you want and it generates more in that style — the headline trick.
- **Simple/tiled model** — author tiles and their allowed neighbors explicitly (like a jigsaw with edge sockets). More control, common for game levels.

## Contradictions & Backtracking

Because it's greedy, WFC can paint itself into a corner (a cell with zero valid tiles):
- **Restart** — simplest: throw away and re-run (fine for small grids).
- **Backtrack** — undo recent collapses and try alternatives (robust but slower; needs snapshots).
- **Reduce contradiction risk** — better constraints, weighting, or pre-seeding fixed cells (a guaranteed entrance/exit).

## Tuning & Control

- **Tile weights** bias frequency (more grass than rare treasure).
- **Pre-constraints** — fix border tiles, force a path, plant landmarks, then let WFC fill around them — this blends authored structure with generated detail.
- **Symmetry / rotation** of tiles expands variety from few assets.
- **Performance** — propagation is the cost; efficient worklists and bitset option-sets matter for big grids. WFC scales to modest maps; for huge worlds, run it per-chunk.

WFC's appeal is the ratio: a handful of tiles or one example image in, endlessly varied yet locally-consistent output out — content that looks designed, generated by constraint rather than by scripting every case.
